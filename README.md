# B-deshi Café

Menu-first website for B-deshi Café. The site is intentionally focused on browsing the café menu rather than ordering online.

## Included

- Responsive Just Ordered-inspired café interface
- B-deshi Café logo and warm cream/coffee/gold palette
- Menu board gallery using the supplied menu artwork
- Category filtering
- QR code that opens the live menu section directly
- Print-ready QR card

## Deployment

This is a zero-build static site. Deploy the repository root directly through Vercel.
